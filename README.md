# Quiz-de-conhecimentos-gerais-9-A
O aplicativo “Quiz Star Quest” é uma plataforma interativa que vai além de um simples quiz, permitindo que os usuários testem seus conhecimentos, sua cultura geral, seu raciocínio lógico e seus níveis de aprendizagem de maneira divertida e dinâmica. A proposta do projeto é transformar o aprendizado em uma experiência envolvente.
